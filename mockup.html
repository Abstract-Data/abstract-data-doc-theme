Quickstart

Install the Abstract Data Starlight theme and have a branded documentation site running in under five minutes.

Installation

Add the theme to your Astro project as a Starlight plugin. The package ships fully configured — drop it in astro.config.mjs and the brand surfaces apply automatically.

terminalcopy
# add the theme
bun add @abstractdata/starlight-theme

Then register the plugin in your Starlight config:

astro.config.mjscopy
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import abstractData from '@abstractdata/starlight-theme';

export default defineConfig({
  integrations: [
    starlight({
      title: 'Acme Docs',
      plugins: [abstractData({
        motion: 'full',    // 'full' | 'calm'
        credit: 'auto',    // 'auto' | 'hide'
      })],
    }),
  ],
});

Tip

HUD mode respects prefers-reduced-motion and disables all animations automatically when the user's OS requests it. No extra config required.

Verify the install

Run the dev server and navigate to localhost:4321. You should see the HUD surface with your project's title in the top bar.

terminalcopy
bun dev

Heads up

Set a custom site URL in astro.config.mjs before production builds, or your sitemap will point to localhost.

Danger

Don't commit your .env file. Use 1Password CLI or your secret manager.

What's next

  • Configure your brand colors (or accept the Abstract Data defaults).
  • Switch to Calm mode for client projects that want less visual energy.
  • Wire up GitHub Pages deployment.

Surface 03 · Toggle

Calm Mode (motion: 'calm')

One-line config flag flips off the hex grid, scanline, particles, holographic shimmer, glitch, and most glow. Same palette, same fonts, same components — just calmer. Recommended for clients with long-form prose-heavy docs.

A calmer surface for client projects. Same brand DNA, no animations.

Same one-line install. The only change is the motion flag.
