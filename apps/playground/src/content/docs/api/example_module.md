## Functions

### `normalize`

```py
def normalize(value: float, lo: float = 0.0, hi: float = 1.0) -> float
```

Clamp `value` to the inclusive `[lo, hi]` range.

**Arguments**:

- `value` _float_ — The number to clamp.
- `lo` _float, optional_ — Lower bound. Defaults to `0.0`.
- `hi` _float, optional_ — Upper bound. Defaults to `1.0`.

**Returns**:

- `float` — The clamped value.

**Raises**:

- `ValueError` — If `lo > hi`.

**Example**:

```py
>>> normalize(1.7)
1.0
>>> normalize(-0.3, lo=0, hi=1)
0.0
>>> normalize(0.42)
0.42
```

### `lerp`

```py
def lerp(a: float, b: float, t: float) -> float
```

Linear interpolation between `a` and `b` by parameter `t ∈ [0, 1]`.

**Arguments**:

- `a` _float_ — Start value.
- `b` _float_ — End value.
- `t` _float_ — Interpolation parameter; `0` returns `a`, `1` returns `b`.

**Returns**:

- `float` — The interpolated value.

**Example**:

```py
>>> lerp(0.0, 10.0, 0.5)
5.0
```

## Classes

### `Range`

```py
class Range(lo: float, hi: float)
```

A closed numeric range with helpful operations.

**Arguments**:

- `lo` _float_ — Lower bound, inclusive.
- `hi` _float_ — Upper bound, inclusive.

**Raises**:

- `ValueError` — If `lo > hi`.

#### `Range.contains`

```py
def contains(self, value: float) -> bool
```

Return `True` if `value` falls within the range.

**Arguments**:

- `value` _float_ — The value to test.

**Returns**:

- `bool` — `True` if `lo ≤ value ≤ hi`.

#### `Range.clamp`

```py
def clamp(self, value: float) -> float
```

Clamp `value` to the range.

**Arguments**:

- `value` _float_ — The value to clamp.

**Returns**:

- `float` — `lo` if `value < lo`, `hi` if `value > hi`, else `value`.
